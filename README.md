# Casino Games

Browser games built with plain HTML, CSS and JavaScript. Nothing to install or build.

## Card Counting Academy

`card-counting-academy/index.html` is an 11-stage trainer for learning to count cards in blackjack, from beginner to expert:

1. Card Values (Hi-Lo)
2. Running Count
3. Cancellation
4. Deck Countdown
5. Deck Estimation
6. True Count
7. Basic Strategy
8. Bet Spreading
9. Illustrious 18
10. Other Systems (KO, Hi-Opt I/II, Omega II, Zen)
11. Casino Floor: a full six-deck blackjack game with count checks

Open the file in a browser to play. Progress is saved in your browser's localStorage.
